# Contributing to Lookbook Studio

Thank you for considering contributing to Lookbook Studio! Contributions are what make the open-source community an amazing place to learn, create, and grow.

## How to Contribute

### Reporting Bugs

1. Check existing [issues](https://github.com/hafizbilalakbar/lookbook-studio/issues) to avoid duplicates
2. Open a new issue with a clear title and description
3. Include steps to reproduce, expected behavior, and actual behavior
4. Add screenshots if applicable

### Suggesting Features

1. Open an issue with the `feature-request` label
2. Describe the feature, its use case, and why it would benefit the project
3. Include mockups or examples if possible

### Submitting Pull Requests

1. Fork the repository
2. Create your feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes following the code style below
4. Test your changes thoroughly
5. Commit with a clear message (`git commit -m 'Add amazing feature'`)
6. Push to your branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

### Code Style

- Follow existing code conventions and patterns
- Use TypeScript for all new files
- Use Tailwind CSS for styling
- Keep components focused and small
- Write meaningful variable and function names

### Commit Messages

- Use the present tense ("Add feature" not "Added feature")
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...")
- Keep the first line under 72 characters
- Reference issues and pull requests when applicable

## Development Setup

```bash
# Clone your fork
git clone https://github.com/your-username/lookbook-studio.git
cd lookbook-studio

# Install dependencies
npm install

# Start development server
npm run dev

# Run type checks
npm run lint

# Build for production
npm run build
```

## Pull Request Guidelines

- Update the README.md if needed
- Keep pull requests focused on a single change
- Ensure the build passes before submitting
- Add screenshots for UI changes
- Describe what changed and why

## Code of Conduct

This project follows the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.
